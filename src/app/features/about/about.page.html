About About This App Histovis Image Visualization & Analysis Platform

Histovis is a cross-platform application designed for high-resolution image management, visualization, and AI-powered analysis — entirely from the web.

This app is originally authored by Ashuin Sharma, leveraging modern web technologies including Ionic 8.7, Angular 20 and OpenSeaDragon 5.0.

Objetivo General

Desarrollar una plataforma web extensible para la visualización, categorización, búsqueda y análisis de imágenes de laminillas para estudios de histoquímica e inmunohistoquímica.

Objetivos Específicos O1 Crear un corpus digital de imágenes de laminillas de muestras de tejido. O2 Implementar un módulo de carga, búsqueda, categorización, anotación manual y visualización de laminillas digitalizadas en alta resolución con soporte para acercamientos y desplazamiento sobre la imagen. O3 Diseñar un módulo de herramientas extensible que permita realizar análisis o transformaciones sobre las imágenes o secciones de las mismas. O4 Integrar al módulo de herramientas al menos una funcionalidad de inteligencia artificial con un modelo de aprendizaje automático preentrenado para el análisis de expresión de proteínas mediante la técnica de inmunohistoquímica utilizando laminillas digitalizadas. O5 Evaluar la pertinencia y aplicabilidad de la plataforma mediante un caso de estudio y un cuestionario estandarizado.
